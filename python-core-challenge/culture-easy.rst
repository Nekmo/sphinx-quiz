Where does the name "Python" come from?
=======================================

.. quiz-question::
   :data-seconds: 25

.. quiz-choices::
   :data-randomize: true
   :data-correct: 2

   * The snake species.
   * The BBC comedy show *Monty Python's Flying Circus*.
   * Guido van Rossum's pet.
   * A contraction of "Pythagoras".

Answer
------

Guido van Rossum named the language after *Monty Python's Flying Circus*,
not the snake.

What is the name of Python's official third-party package repository?
=====================================================================

.. quiz-question::
   :data-seconds: 20

.. quiz-choices::
   :data-randomize: true
   :data-correct: 2

   * npm.
   * PyPI.
   * PythonHouse.
   * CRAN.

Answer
------

PyPI, the Python Package Index, hosts the third-party packages you install
with ``pip``. npm belongs to Node.js and CRAN to R; "PythonHouse" is not a
real thing.

Is Python case-sensitive?
=========================

.. quiz-question::
   :data-seconds: 25

.. quiz-choices::
   :data-randomize: true
   :data-correct: 2

   * No, ``Name`` and ``name`` are the same.
   * Yes, ``Name`` and ``name`` are different.
   * Only inside functions.
   * Only for built-in names.

Answer
------

Python is case-sensitive: ``Name``, ``name``, and ``NAME`` are three
different identifiers.

How is typing handled in Python?
================================

.. quiz-question::
   :data-seconds: 25

.. quiz-choices::
   :data-randomize: true
   :data-correct: 2

   * You must declare every variable's type.
   * Variables are dynamically typed.
   * Every variable is a string until converted.
   * Types cannot change once assigned.

Answer
------

assign to it, and that can change over time.
