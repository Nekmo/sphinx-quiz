Where does the name "Python" come from?
=======================================

.. quiz-question::
   :data-seconds: 20

.. quiz-choices::
   :data-randomize: true
   :data-correct: 3

   * The snake genus *Python*.
   * The Greek mythological serpent slain by Apollo.
   * The BBC show *Monty Python's Flying Circus*.
   * The initials of its first three modules.

Answer
------

Guido van Rossum was reading the published scripts of *Monty Python's
Flying Circus* while implementing the language. That's also why examples
use ``spam`` and ``eggs`` instead of ``foo`` and ``bar``.

Who was Python's BDFL until 2018?
=================================

.. quiz-question::
   :data-seconds: 25

.. quiz-choices::
   :data-randomize: true
   :data-correct: 2

   * Tim Peters
   * Guido van Rossum
   * Raymond Hettinger
   * Barry Warsaw

Answer
------

Guido van Rossum, Python's creator, was the *Benevolent Dictator For
Life* until he stepped down in 2018 after PEP 572. Since then Python is
governed by a five-member Steering Council.

What does ``import this`` print?
================================

.. quiz-question::
   :data-seconds: 25

   * *The Zen of Python*, by Tim Peters.
   * The full list of built-in modules.

Answer

"Beautiful is better than ugly" and "Readability counts".

What does PEP stand for?
========================

.. quiz-question::
   :data-seconds: 25

.. quiz-choices::
   :data-randomize: true
   :data-correct: 4

   * Python Extension Protocol
   * Python Executable Package
   * Python Evaluation Process
   * Python Enhancement Proposal

Answer
------

*Python Enhancement Proposal*: the design documents driving the
language's evolution since PEP 1 (2000). Famous ones: PEP 8 (style
guide), PEP 20 (the Zen) and PEP 484 (type hints).
